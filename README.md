# Jarvey Homebrew tap

```
brew install comind-ai-tech/tap/jarvey
```

[Jarvey CLI](https://jarvey.io): Jarvey's calls, recaps and workspace memory
in the terminal, for people and for the agents they run. Every command takes
`--json`.

This repository holds release builds and the Homebrew cask only. The same
builds install with npm: `npm install -g jarvey`.
